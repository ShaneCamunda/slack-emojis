# slack-emojis

Custom Slack emojis I've created (generated with ChatGPT, cleaned up and resized). Archive so I never have to rebuild them.

## Contents

- `emojis/` — the finished emoji files. The filename (without extension) is the Slack emoji name.
- File types: transparent PNG preferred. GIF, JPG, and WEBP are also allowed.

## Adding a new emoji

1. Drop the file into `emojis/` using a lowercase-hyphenated name.
2. Commit to `main`. The catalog table below updates itself (see `scripts/update_catalog.py` and `.github/workflows/update-catalog.yml`).

To rebuild the table by hand: `python3 scripts/update_catalog.py`
